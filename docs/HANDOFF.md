# HANDOFF — Flicksy-Download (برای ادامهٔ کار در چت جدید)

آخرین به‌روزرسانی: 2026-11-15 · ریپوی تست: https://github.com/amirhossein-rashidi/flicksy-download · شاخهٔ کاری: `phase-1-security`
(ریپوی اصلی Flicksy **دست‌نخورده** است و نباید تغییر کند.)

## قوانین همکاری با مالک (همیشه رعایت شود)
- به فارسی پاسخ بده. مالک برنامه‌نویس نیست؛ **فایل کامل** بده، نه تکه‌کد/دیف. یک مرحله، منتظر تأیید، بعد مرحلهٔ بعد.
- لینک‌های آمادهٔ کلیک را خودت کامل بساز (مثلاً `http://127.0.0.1:8090/api/v2/health`)، نه اینکه او بسازد.
- بازنویسی بی‌دلیل ممنوع: اول موجودی/چک‌لیست، بعد تغییر تدریجی، بعد تست مقایسه‌ای.
- مالک اغلب به‌خاطر کیبورد انگلیسی تایپ می‌کند؛ همیشه فارسی جواب بده.
- هر بار فایل‌ها را zip کن و بفرست؛ مالک روی ویندوز با `python -m flicksy_dl` اجرا می‌کند.

## محدودیت‌های سخت
- فقط ریپوی تست. بدون deploy، بدون ساخت منابع Cloudflare (D1 و …). push فقط به ریپوی تست و با اجازهٔ مالک.
- آرشیو اصلی (`data/archive.json`) تغییرناپذیر؛ داده‌ای بی‌صدا حذف/بازنویسی نشود.
- **لینک‌های دانلود (Sermovie/mehracdn/SayMyName…) تا تأیید مجوز انتشار فقط محلی بمانند.** `data/` در `.gitignore` است؛ هرگز commit نشود. برای هر بسته/سایت عمومی از `FLICKSY_EXPOSE_LINKS=0` استفاده شود.
- فایل رسانه‌ای دانلود نشود. فقط منابع مجاز؛ دور زدن لاگین/کپچا/paywall ممنوع. شکست HEAD دلیل مرده‌بودن لینک نیست.
- شبکهٔ اجتماعی نیست: بدون پروفایل/فالو/واچ‌لیست/امتیاز/ریویو/پیشنهاد/صفحهٔ بازیگر.

## وضعیت فعلی
- Phase 1: سخت‌سازی امنیتی `server.py` (۱۴۶ تست).
- Phase B: `python -m flicksy_dl.importer` (آرشیو→SQLite با FTS5، overlayها)، API محلی `/api/v2` (`python -m flicksy_dl` روی 127.0.0.1:8090)، رابط وب بدون build (طرح مالک: کاروسل پوستر، ژانرهای مرتب‌شده ۳۵+نمایش بیشتر، جزئیات، فصل/قسمت، وضعیت لینک).
- **چک‌کنندهٔ لینک (جدید):** `python -m flicksy_dl.linkchecker --limit 100` → فقط HEAD/GET با `Range: bytes=0-0` و بدون خواندن بدنه؛ نتیجه در `data/overlay/link-status.json`؛ بعد دوباره `python -m flicksy_dl.importer` برای اعمال. فقط جواب قطعی (۲xx غیر HTML ⇒ working؛ ۴۰۴/۴۱۰ تأییدشده با GET ⇒ unavailable) وضعیت را عوض می‌کند؛ بقیه unverified می‌مانند و نتیجهٔ قطعی قبلی هیچ‌وقت با نتیجهٔ نامشخص پایین نمی‌آید. آدرس‌های خصوصی/لوپ‌بک رد می‌شوند.
- **مولد استاتیک (جدید، معماری B):** `python -m flicksy_dl.staticgen` → پوشهٔ `public/` (ایندکس عناوین + قطعات جزئیات + کلاینت API استاتیک). **قفل لینک:** URL فقط با `--publish-links` و فقط برای میزبان‌های `data/overlay/publish-hosts.json` نوشته می‌شود؛ پیش‌فرض: هیچ لینکی. مالک تصمیم گرفته سایت «عمومی برای همه» باشد، ولی هر میزبان باید صراحتاً در فهرست مجاز باشد.
- ۱۷۶ تست پاس (`python -m pytest`).

## مشکلات/یافته‌های شناخته‌شده
- فقط سریال MobLand فصل/قسمت ذخیره‌شده دارد؛ بقیه فقط از فایل scan (تطبیق عنوان لاتین).
- ۲٬۶۵۱ لینک scan بی‌تطبیق، ۵۸۷ مبهم (علامت‌گذاری‌شده، حدس زده نشده).
- ۵ رکورد اطلاعیهٔ نرم‌افزار (ids 35871, 35849, 35848, 35835, 31167) با ~۵۰ ژانر؛ فقط از `/featured` کنار گذاشته شدند.
- پوسترها از میزبان‌های ثالث و فونت از Google Fonts بارگذاری می‌شوند.

## گام‌های بعدی (پیشنهادی)
1. اجرای واقعی چک‌کننده روی کامپیوتر مالک (دسته‌های ۱۰۰–۲۰۰ تایی، با `--host` برای مهربانی با هر میزبان).
2. افزودن فصل/قسمت بیشتر از طریق `data/overlay/seasons.json`.
3. مولد بستهٔ استاتیک (معماری B: کاتالوگ استاتیک + ایندکس عناوین) **بدون لینک‌های دانلود** برای میزبانی عمومی، تا مجوز انتشار تأیید شود.
4. آداپتورها/همگام‌سازی منابع مجاز؛ لایهٔ API-client از قبل جداست (`docs/API-CONTRACT.md`).
